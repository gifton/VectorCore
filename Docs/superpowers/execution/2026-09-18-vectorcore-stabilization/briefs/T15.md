# T15 brief: cosine distance maps NaN and infinite inputs to distance 0, so such rows rank nearest (root-created; from P01 phase E)

## Finding
- `CosineKernels.calculateCosineDistance` (`Sources/VectorCore/Operations/Kernels/CosineKernels.swift` ≈17-35) computes `1 - max(-1, min(1, similarity))`.
  - Swift's `min(1, NaN)` returns `1`, so a NaN similarity gives distance 0, the best possible score. Root verified this from source.
  - A row containing ±∞ gives ∞/∞ = NaN similarity, and so also distance 0.
  - P01 phase E observed the fused cosine routes ranking NaN and ±∞ rows FIRST, on both the base and phase E trees.
- The Top-K NaN contract (numeric before NaN) only helps if the score is NaN. This clamp hides the NaN before selection, so the contract never sees it.
- `calculateCosineDistance` has 14 references. Other cosine implementations may differ: the generic `CosineDistance` witness, preNorm, the FP16/mixed-precision cosine, SoA cosine, and the batch fused range kernels.
