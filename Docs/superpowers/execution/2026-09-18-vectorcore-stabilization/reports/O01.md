## Investigation and RED evidence

The enum retains a `CompactBuffer` class, but the old uniqueness method probed its inner ManagedBuffer reference. Multiple value copies therefore shared one outer owner whose inner reference still appeared unique. ManagedBuffer also does not destroy manually initialized tail elements; no owner supplied that destruction. Singleton import read column one after validating a size-one square matrix.

Tests were added before production changes. Initial test compilation caught a Swift Testing macro restriction on mutating `setAt` calls within `#expect`; storing its Bool result before assertion corrected the test.
