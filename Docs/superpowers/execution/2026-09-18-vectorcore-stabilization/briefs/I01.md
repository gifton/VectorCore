# I01 — Invalidate normalization metadata at mutable access

Status: approved narrow Core repair, eligible before S01 under the catalog's staged-closure rule. S01 shape validation and executed downstream checks remain prerequisites to full finding closure.

## Root contract

The wrapped vector is authoritative. Every writable access through `NormalizationHint` invalidates `isNormalized` and cached magnitude before publishing or yielding mutable access, even when the final value is equal, a closure makes no write, or a closure throws. Existing writes completed before a throwing borrow retain the underlying vector's write semantics; clearing hints must not roll them back. Read-only access does not clear hints. Direct replacement, nested `.vector` subscript/storage mutation, wrapper `.storage`, protocol-generic storage replacement, and successful/throwing mutable buffer access are all covered.

Use a stored backing vector plus a public computed `vector` getter/setter/`_modify` (or an equally explicit design that invalidates before yield). Setter and `_modify` clear both caches before mutation. Do not only add `didSet` after an operation. Keep ordinary public member access source-compatible; declaration annotations must respect Swift's inlinability/access rules. Existing explicit `isNormalized: true` construction remains a caller assertion, not a numerical verification service. Auto-detection behavior is out of scope for this task; N01 owns magnitude/normalization range safety.

Decoded normalization fields are advisory and untrusted. Decode the vector, clear both hints, and do not compute magnitude as part of decoding. Retain the existing encoded keys (`vector`, `isNormalized`, `cachedMagnitude`) for wire compatibility; old payloads with valid vector data still decode. Ignore hint field contents, including missing/incorrectly typed advisory fields. Document that a Codable round trip preserves coordinates but clears hints and may therefore change wrapper equality/hash, which currently includes the normalization bit. Rebuilding an explicit trusted hint is the migration for a caller requiring it.

The wrapper cannot observe external aliases inside arbitrary reference-semantic custom conformers. Document the IndexableVector/NormalizationHint obligation: a caller asserting normalization must supply a stable value/snapshot and must not mutate untracked aliases while relying on the assertion. Do not claim the wrapper makes all custom reference types immutable or thread-safe.

## Mechanical regression design

Build one generic exercise for each built-in IndexableVector representation: DynamicVector, Vector384Optimized, Vector512Optimized, Vector768Optimized, Vector1536Optimized and generic fixed Vector with applicable static dimensions. FP16 and INT8 currently lack IndexableVector conformance and must be named as exclusions, not silently omitted from an 'all representations' claim. Do not add conformance here.

Start each route with coordinates `[1,0,...]` and an explicitly true hint; mutate the first coordinate to 2, so independent scalar magnitude is exactly 2. Assert coordinates, `isNormalized == false`, `cachedMagnitude == nil`, and magnitude 2 (finite, within a tight tolerance). Include initially false auto-detected hints with a nonnil cached magnitude to verify that cache is cleared too. Test every applicable route:

- Whole wrapped-vector replacement; same-value replacement also clears.
- Nested `.vector[0] = 2` on concrete mutable-subscript types.
- Nested `.vector.storage` mutation and replacement.
- Wrapper storage replacement and element mutation, direct and via `V: VectorProtocol` generic helper.
- Wrapper mutable-buffer writes returning normally and throwing a known error after a write.
- Nested wrapped-vector mutable-buffer write throwing after a write, exercising `_modify` unwind.
- A mutable borrow with no writes conservatively clears; read-only vector/storage/buffer access retains hints.
- A retained copy remains unchanged in coordinates and hints after mutation of the other value.

Use shape-preserving inputs only until S01; do not let known malformed-shape traps contaminate this regression. Where storage element is SIMD rather than scalar, mutate a lane through representation-specific adapters and route shared assertions through the generic exercise. No test may substitute a direct `invalidateHints` call for a public mutation.

For decoding, start from an encoded actual vector, vary only hint fields to true/false, stale magnitude, missing and incorrect types. Decoded coordinates and shape must match; hints must be false/nil in all cases. Test both fixed and dynamic representations, and a normal encode/decode round trip. The previous round-trip expectation that true survives decoding must be updated explicitly, not weakened into no assertions.
