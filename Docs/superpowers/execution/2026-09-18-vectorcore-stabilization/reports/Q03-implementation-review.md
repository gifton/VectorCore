### State, arithmetic and recording review

Every read/write of State.isEnabled, State.statistics and hasFiniteValue is under the same NSLock. Initialization precedes publication. enable replaces/reset-enables one locked state; disable preserves statistics; reset preserves enabled; snapshots copy the whole value. Local Summary classification never reads shared state, and commit rechecks enabled before atomically merging the whole batch. The synchronized false preflight may skip later-enabled work; a prepared summary can join a newly reset enabled generation. Documentation precisely states those allowed semantics rather than an epoch/count-every-conversion promise. All logging occurs after unlock from immutable summary/call data. No hardware/profiler state is touched.

Independent nonnegative saturating counters use addingReportingOverflow; rates convert individual counters to Double before division. The internal seed seam preserves enabled, resets finite-range state and is used only to reach otherwise infeasible saturation boundaries through the real commit. Public statistics is a value snapshot; callers mutating their own copy cannot mutate recorder state. Exceptional counters are exclusive per event before saturation; the tests correctly avoid overflowing counter-sum arithmetic.

Classification checks original NaN first, then only finite inputs for infinity/zero/subnormal rounded encodings. Input infinities contribute total but no overflow. Finite original nonzero values with either signed rounded zero count underflow; finite subnormal output uses exponent-zero/nonzero-fraction bits. Range tracks original finite values independently and initializes from the first finite event. Explicit zero tie rules work within Summary and across commits: mixed signs yield min -0/max +0; lone signs survive. No-finite/empty/reset range remains +0/+0.

The three fixed-width constructors pass their already-generated storage into the narrow recorder. Conversion kernels, output bits, storage checks, raw-bit initializers, reverse conversions and O05 scoped-borrow APIs are unchanged. The helper no longer expands original lanes into an intermediate Float array or reconverts constructor outputs. Its shape arithmetic is bounded by the actual512/768/1536 callers; no arbitrary custom-size safety contract is introduced. SoA paths retain existing constructor calls and do not add padding events.
