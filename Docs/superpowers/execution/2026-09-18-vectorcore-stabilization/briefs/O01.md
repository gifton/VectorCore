## Contracts and root design rulings

1. A copied TieredStorage/TriangularMatrix is a value snapshot. Compact mutations through subscript, setAt and mutable-buffer access cannot change another copy or an already-created iterator's snapshot.
2. Uniqueness must be checked at the actual shared owner. Today `CompactBuffer` is a class wrapping a ManagedBuffer; `isKnownUniquelyReferenced(&buffer)` checks the inner reference even when the outer class is shared. Repair the owning representation/check. Avoid an unconditional full copy per scalar write. When checking a reference extracted from an enum, account for the enum's own incidental retain before testing uniqueness. Root approves moving the payload out temporarily and restoring it or a comparably explicit ownership design.
3. Exactly the initialized tail elements must be deinitialized once by their allocation owner. Prefer a ManagedBuffer subclass owning tail destruction, or an equally provable ownership design; never deinitialize unused capacity. Copies retain their own logical element references and replacements release the replaced reference. No early destruction while another copy/iterator still owns the value.
4. Compact mutable-buffer writes already performed persist when the closure throws, and other copies remain unchanged. O02 owns general inline/standard throwing writeback and standard/aligned per-write copy amplification. Do not claim those are fixed here.
5. `TriangularMatrix.fromFullMatrix([])` remains nil. A valid `[[value]]` returns a size-one matrix with zero stored off-diagonal elements and round-trips to `[[0]]` for numeric types. A square two-by-two input stores its upper off-diagonal value; malformed/ragged input returns nil. This method currently indexes `[0][1]` even for a singleton; use an available validated element to seed an empty storage allocation rather than reading a nonexistent column. Do not expand into triangular integer-overflow policy (E01).
