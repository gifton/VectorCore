# S03 independent design review

**Verdict: ACCEPT.** Read the candidate brief and corresponding TopKResult, SearchResult/SearchResults, generic/dynamic serialization, all four optimized Float decoders, all three INT8 decoders, LinearQuantizationParams and NormalizationHint decoder paths. Inspected FP16/SoA/storage definitions for Codable exposure. No source edits, builds or delegation were performed.

The actual TopKResult decoder directly assigns separately decoded arrays without the direct initializer's length guard. A mismatch can silently truncate through toTuples and SearchResults(from:) or fail during indexed access. Decoding local arrays, validating equal counts and throwing dataCorruptedError at distances before assignment closes that construction route without changing valid encoding. The keyed error preserves enclosing coding paths. Baseline RED should inspect counts only, as required, rather than invoke a trapping consumer.

The valid-wire policy is appropriately limited to the actual representation: unchanged indices/distances keys and array order, arbitrary Int labels including duplicates/extremes, and arbitrary distance classifications allowed by the chosen decoder strategy. Sorting, deduplication, score restrictions or metadata plausibility checks would be incompatible additions and are explicitly excluded. JSON nonfinite strings exercise decoder policy without promising NaN payload preservation; finite/signed-zero checks should use the format's actual represented value. Parsed-structure comparisons avoid treating object key order as a schema guarantee.

The maintained table correctly distinguishes keyed generic Vector elements, DynamicVector dimension/elements, single-array optimized Floats and keyed INT8 storage/quantizationParams. Existing generic/optimized routes delegate exact-count rejection to their throwing initializers; their errors need not be relabeled dataCorrupted merely to match TopK. DynamicVector validates count against its declared dimension before constructing storage, so negative/extreme declared dimensions with short arrays need no large allocation. INT8 decoders validate 128/192/384 SIMD4 entries before invoking their guarded constructors, while ordinary scalar/lane decoder failures remain separate evidence.

Q01's parameter tuple must be preserved as stored rather than recalibrated. The proposed tests retain positive subnormal scale, finite equal bounds and the full asymmetric Int32 zero-point domain; rejecting decoded tuples merely because later dequantization overflows would change the accepted Q01 contract. Invalid standalone and nested parameter cases must independently exercise every width and each invalid field. Raw codes and the five stored fields are the preservation oracle, not recomputed floating coordinates.

NormalizationHint intentionally ignores encoded hint/cache values and reconstructs false/nil after decoding its nested vector. Testing malformed nested vectors and even obsolete ill-typed hint metadata verifies I01 rather than reversing it. SearchResult/SearchResults synthesize nested-record Codable and need only valid legacy/adapter coverage here: their scores, times and candidates metadata are not parallel-array invariants. The TopK adapter can remain unchanged once all recoverable decoding preserves the length invariant. R05's score behavior and R04's selection work remain outside the write scope.

The inspected FP16 vector structs and SoA/storage wrappers do not expose their own Codable declarations in these definitions; the requested explicit inventory should record this bounded fact, including any conformance extensions found by the worker, without adding serialization or claiming every library Codable type is covered. Generic Vector encoding its storage as scalar elements does not confer Codable on its storage wrapper.

The proposed RED, exact TopK error family/path/count checks, legacy base-encoded fixtures with hashes, independent malformed-case tables and focused Debug/Release matrix are sufficient for this recoverable decoder repair. No ASan, crash test, binary-format edit or broad decoder rewrite is warranted. Any new S01/Q01 discrepancy must return to root for ownership adjudication; their already accepted invariants should receive regression coverage rather than duplicate closure credit.

No design blocker or valid-wire contradiction found. Implementation acceptance still requires the frozen full patch, explicit representation/case counts and executed evidence described in the brief.
