## What is required, and what remains a recommendation

`Package.swift` and README advertise VectorCore on macOS 14+, iOS 17+, tvOS 17+ and visionOS 1+. CONTRIBUTING explicitly says deployment targets do not promise runtime tests on every device. Mac Catalyst is an explicit CI compilation target. `VectorCoreBenchmarking` and `vectorcore-bench` are macOS host tooling; compiling the former across the CI matrix does not promise mobile support. watchOS and Linux remain outside advertised support.

The existing required CI combinations are Xcode 16.2 and 26.3 × Debug and Release native tests, Release compilation of both library products × iOS/tvOS/visionOS simulators and Catalyst, and default-Debug `--build-tests --triple x86_64-apple-macosx14.0`.
