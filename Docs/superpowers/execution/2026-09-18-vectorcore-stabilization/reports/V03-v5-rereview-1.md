## New-breakage checks
- No-rebuild false positive: patterns are line-anchored (`^[N/M] Compiling|Linking`, `^Build complete!`, `^Compiling `). dyld lines, test output and verbose argv echoes do not begin that way. Implementer scanned all 232 stdout/stderr files of the r2 ASan/TSan runs: 0 hits (report claim; I did not re-scan). Residual risk: a test body printing a line that starts with "Compiling " would fail the gate loudly (safe direction). Not a defect.
- No-rebuild false negative: the check recognises native-style progress and "Build complete!". A relink that prints only "Building for debugging..." or only a verbose swiftc/ld argv, with no progress lines, would pass. This is the same strength as the pre-existing perf check, now shared; it is best-effort, and the comment says what it matches. Low-grade limitation, unchanged by this round. Severity: informational.
- find_swift timeout: finite (60 s default, passed through to run, which enforces it). Not overridden to None at either call site.
- Ordering: find-swift now precedes the build. If xcrun fails or returns a non-file, the driver aborts earlier with ProductError (a ValueError) after creating the output dir and find-swift.json, before any scratch exists. Previously xcrun failure surfaced only after a 20-minute build; xcrun was already a hard requirement, so no case newly fails except failing sooner. One behavioral change: the build now uses the xcrun-resolved swift rather than PATH swift; xcrun honours DEVELOPER_DIR/TOOLCHAINS, and the CLAUDE-recorded runs showed both resolve to the same toolchain, but a PATH-selected non-Xcode swift would now be ignored. Intentional per item 4. Not exercised live this round (implementer says so; root's final seal must run the gates).
- Association strictness: unchanged. `str(host) not in log or not in_log(bundle, log)` and the sanitizer-runtime check are untouched in the diff; the perf host/bundle checks are also unchanged. The only diff touching them is `swift_path.strip()` -> `swift_path`, equivalent because find_swift already strips. `toolchain = Path(swift_path).resolve().parents[1]` equals the prior value.
