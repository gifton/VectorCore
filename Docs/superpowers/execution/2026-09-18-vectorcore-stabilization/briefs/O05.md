# O05 — Remove escaped storage views and scope FP16 borrows

Root-approved design; independent ACCEPT is recorded in reports/O05-design-review.md. Dispatch after accepted O03, with exclusive DimensionStorage/UnifiedStorage/MixedPrecisionKernels ownership. Q03 and Q04 also touch MixedPrecisionKernels and cannot overlap. Candidates OWN-15/16/17 plus the qualified context OWN-24. Breaking public getter removal is authorized. No supported-use UAF has been reproduced; do not relabel source-established lifetime defects as runtime reproductions.

## Chosen disposition

Delete the unused internal StorageSlice type and ManagedStorage/DimensionStorage slice-returning helpers. Current source inventory finds only declarations and forwarding calls; confirm again at the dispatch base. Preserve the public DynamicVector.slice, which returns owned vector storage and has a different contract. No replacement slice feature is needed without a caller. Removal closes the dangling-view route without adding an owning-slice abstraction or inline-to-heap promotion.

Delete the disabled MoveOnlyStorage experimental implementation and its MOVE_ONLY_EXPERIMENTAL block in UnifiedStorage. Current package has no gate setting or executable consumer. Do not enable the gate, repair it by suppressing deinit, expose a transfer API or infer that a raw pointer becomes an owner. The chosen closure is removal of the dormant defective route, not proof of a new exactly-once move-only transfer implementation. Inventory all references before deletion, including read-only sibling source. Record the difference from the historical gate-enabled fixture acceptance: no such route remains to validate, and no experimental performance claim survives.

Remove fp16Storage pointer getters from Vector512FP16, Vector768FP16 and Vector1536FP16. Replace each with public synchronous `withUnsafeFP16BufferPointer<R>(_ body: (UnsafeBufferPointer<UInt16>) throws -> R) rethrows -> R`, forwarding the body within storage.withUnsafeBufferPointer. The immutable ContiguousArray owner remains alive for the entire callback. Expose exactly the fixed dimension of bit patterns, with no conversion, mutation, copy requirement or retained raw pointer. Body runs once; return value and identical thrown error propagate. Temporary-expression owners are supported for this synchronous scoped use.

This is explicitly an unsafe borrowing API. Document that the buffer/base pointer must not escape through a returned value, captured variable, task, foreign callback or stored pointer; arbitrary generic R does not enforce this rule in the type system. Do not describe it as compiler-enforced nonescape or a safe async borrow. For asynchronous/retained data, the migration example copies values into an owned Array inside the callback and retains that value. No async scoped overload, unchecked wrapper or cancellation/lifetime guarantee is introduced.

Direct FP16 kernels already nest ContiguousArray.withUnsafeBufferPointer borrows. Re-inventory their actual callers and keep those scoped routes; do not rewrite arithmetic or require all internal direct borrows to route through the new public wrapper. SoAFP16.storage is an owned ContiguousArray value, not the removed pointer getter. Preserve its public value behavior. Preserve I01 hint invalidation, S01 shape boundaries, N01 normalization, Q01 quantization and any accepted Q03 diagnostics.

Preserve the frozen FP32 SoA layout, count/allocated-byte distinction, explicit ownership-transfer behavior and caller synchronization duties. OWN-24 is qualified contract context, not a newly reproduced race/UAF. Add a conforming external-style test example with dimension 8, lanes 2 and exactly two SIMD4 storage lanes; assert these obligations explicitly and verify live layout/data at N0/1/5 for ordinary and page-aligned modes. Do not execute an invalid unsafe conformer or create new checked constructor promises. Existing transfer and layout tests remain controls. GPU import/synchronization is not executed.
