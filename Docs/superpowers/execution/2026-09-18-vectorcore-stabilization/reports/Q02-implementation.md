## Delivered behavior

Adaptive width512 distance computes the direct FP32 result once, preserves its bits on the defined fallback paths, screens both operands and verifies the actual reduced result using a Double relative-error comparison. Quantized suggestions validate inputs and use typed complete hint identities under the existing lock. Their hint is explicitly heuristic.

Mixed selection is lookup-only. Explicit calibration executes one reference plus exactly the requested warmup/measured calls for each of five strategies, including per-invocation reduced conversion. Profiles use widened errors and deterministic ties. Kernel selection applies representation permissions and both resource filters to overrides, profiles and fallback; latency filters require matching measured profiles. Full-mode mixed integration returns fullFP32 only after validation and resource-filter rejection. Both calibrators stage publication, check cancellation and retain earlier state on pre-commit failure.

Kernel persistence is opt-in. Exact provenance and typed workloads are decoded before selection or profile-first publication. Invalid individual records are discarded independently; failed saves retain committed in-memory results and report that distinction. Clearing with deletion removes only the configured file before clearing memory. Unknown hardware identity explicitly disables disk reuse. Pool documentation describes an immutable NSLock-protected value cache.

No normal Operations routing, precision activation, arithmetic core, SoA layout, Q03 diagnostic hook, Q04 range wrapper, O05 borrow API, Package or sibling source changed. `Q02-scope-integrity.json` mechanically compares the entire unowned remainder of the two shared kernel files against the exact base.
