## Change and migration

The Float search facades `TopKSelection.nearest`, `batchNearest`, and `VectorCollection.search` now accept `any DistanceMetric<Float>`. The single-query and collection facades open the supplied existential into their existing generic helper; no witness replacement or Euclidean fallback remains. The batch facade forwards that witness per query. All three factory return types are Float-associated; named lookup compares case-insensitive enum raw values, including dotProduct, without changing raw values or adding aliases.

Callers holding `any DistanceMetric` must narrow to `any DistanceMetric<Float>` (or explicitly cast and handle mismatches). Third-party VectorCollection overrides MUST migrate `search(metric: any DistanceMetric)` to `search(metric: any DistanceMetric<Float>)`: the old method can remain only an overload while the new protocol requirement silently selects the default implementation. `constrainedCollectionOverrideDispatchesThroughProtocolWitness` exercises the correctly migrated override through a generic `C: VectorCollection` caller.
