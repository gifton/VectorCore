# N03 — Stable population statistics of vector magnitudes

Root contract. Depends on accepted E03 and exclusive access to BatchOperations.swift; do not dispatch concurrently with E02/E06/R03. NUM-06 closure candidate. This fixes aggregation of the Float magnitudes delivered by the current generic vector.magnitude expression, not component covariance or the magnitude calculation itself. N01 separately repairs those numerical routes. No new magnitude protocol requirement, dispatch change, provider routing or production performance target.

## Observable behavior

For magnitudes m_i, return count=N, meanMagnitude=(sum m_i)/N, stdMagnitude=sqrt(sum((m_i-mean)^2)/N). This is population standard deviation, including N=1 (zero deviation), not sample standard deviation. Empty input retains count0 and both outputs+0. Each vector's existing generic magnitude expression is evaluated once per operation. Different vector dimensions are permitted; this operation summarizes one scalar measurement per vector and does not require component shape equality.

If any delivered magnitude is NaN or either infinity, return the full count and NaN for both numeric outputs. Do not silently exclude it, clamp an invalid variance to zero, or infer finiteness solely from finite input coordinates. A finite coordinate vector can have an unrepresentable Float norm. This is an intentional documented nonfinite-result policy. Existing finiteStatistics continues to filter by finite coordinates and then calls the shared synchronous statistics route; if a retained vector's magnitude is infinite, its result follows this NaN policy. Do not change that filtering predicate or count semantics.

Share one stable Double accumulator between serial, parallel partials and internal SyncBatchOperations.statistics. Root explicitly adds the synchronous route after source inventory found the same Float mean/variance defect there. Float-to-Double widening is exact. Keep the mean and centered sum of squares in Double until final division/sqrt and Float projection. Never use E[m^2]-E[m]^2 and never round the mean to Float before computing deviation. No retained array of all magnitudes or squared deviations is necessary.

Use mergeable centered statistics (count, mean, M2), with a well-justified Welford/Chan update and merge. An update may use delta^2*n/(n+1) for the nonnegative M2 increment; a merge uses delta^2*nA*(nB/(nA+nB)). Compute count ratios/products in Double, never multiply integer counts. Count sums must be checked or derived from disjoint ranges of the same actual array. Every finite Float difference is below2^129, and even Int.max samples keep squared-deviation accumulation below2^321, inside Double range. This is a range bound, not an all-input rounding-error theorem. Preserve exact zero deviation for identical finite magnitudes, including Float(1e18), leastSubnormal and maxFinite.

Parallel reduction must use the same accumulator and merge partials in original chunk-index order, independently of completion order. This provides a deterministic merge order for a given partition; do not promise identical bits for every partition or permutation. Preserve the current public serial/parallel threshold and chunk selection. E06 owns consuming live configuration; N03 must not activate ignored settings, change defaults, or mask invalid setting arithmetic. E02 owns task fan-out and broader scheduling. An internal production-used parallel helper accepting an explicit positive chunk size is authorized so independent tests can exercise multiple actual partitions without global setting mutations. Its statistics-only partition endpoints use start+min(chunkSize, remaining), including chunkSize=Int.max. No new public knob.
