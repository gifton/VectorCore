Admission ordering matches the brief: invalid dimension/cores and disabled mode bypass callbacks before any cache shortcut; published cache precedes in-flight lookup; an in-flight hit returns an unpublished default; reached completed-time cap publishes its default; otherwise the caller reserves the key. A manual set does not remove the active callback's reservation. Successful calculation publishes cache[key] if a manual value arrived, otherwise measured/fallback tuning, then charges elapsed time and retires the reservation atomically.
