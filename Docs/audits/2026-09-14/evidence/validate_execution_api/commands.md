# Commands and evidence limits
All files are isolated; no shared build or repository mutation was performed.

Public probes were compiled with `python3 /private/tmp/vectorcore-review-2026-09-14/build_probe.py SOURCE.swift release` against existing Release objects. Sources: ExtraProbe.swift, search_probe.swift, interfaces_probe.swift, batch_probe.swift, ExecutionPublicProbe.swift. Initial batch subprocess compilation failed only because Swift module cache was sandboxed; individual escalated calls succeeded. Their failed compiler logs are retained and must not be interpreted as source failures. ExtraProbe compiled on its first direct invocation. replay.json and replay2.json record executable commands, exits and normal output. Compiler warns about converting integer + to Sendable combine in ExtraProbe; combine is stateless and this cannot explain endpoint traps.

Pool probe: `swiftc -O -swift-version 6 -parse-as-library Sources/VectorCore/Providers/SwiftBufferPool.swift Sources/VectorCore/Protocols/BufferProvider.swift /private/tmp/vectorcore-validated-audit-2026-09-14/validate_execution_api/ExecutionPoolProbe.swift -o /private/tmp/vectorcore-validated-audit-2026-09-14/validate_execution_api/ExecutionPoolProbe`. Actual sources unchanged; only AlignedMemory.deallocate dependency replaced with locked free counter. Real allocation via posix_memalign, free calls retained. The probe verifies weak actor disappearance, then manually frees the leaked pointer. It proves raw cached-pointer nondeallocation, not generic-element lifetime or actual RSS growth.

Each case ran in a subprocess. negative-heap killed after 3 seconds; nontermination is also a direct invariant proof. Crash logs are SIGTRAP/-5 on this target. Only ExtraProbe normal ran bounded two-row similarity, not a scale benchmark. Batch probe runs 4097x512 SoA to cross tiled routing and uses Float sentinels; initialization of trivial Float does not introduce generic object ownership effects. No TSAN, downstream build or GPU execution.
