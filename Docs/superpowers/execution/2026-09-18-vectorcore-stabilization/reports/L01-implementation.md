# L01 final implementation and verification — v4

The Swift fallback now carries Double matrices, reflector parameters, rotations, convergence decisions and normalization through QR, symmetric eigen and thin SVD. Float conversion occurs only when constructing public results, including after the wide SVD transpose/swap. Stable scaled norms and a scaled smaller Jacobi root replace Float squares and unsafe ratios. Eigen uses the lower triangle only and the approved Frobenius-relative tolerance. SVD compares normalized column correlation with the approved dimension-aware epsilon. Both retain the 60-sweep cap and typed failure on exhaustion. Public shape, layout and spectrum ordering remain unchanged.

Both providers validate finite referenced input after shape validation and reject nonfinite Float results as operationFailed. Values-only eigen does not inspect its unused output workspace. The exact-zero working-column SVD basis exception remains explicit. A separate full-rank subnormal fixture has a nonzero working singular direction whose scalar spectrum rounds to Float zero; it still requires normalized factors. Ordinary Float rounding is allowed, without a relative-accuracy promise below its spacing.

The shared validator checks the largest individual working element width, Double. Every thin output or individual working array has at most the input element count. This checks representability, not aggregate memory budget or allocation success. C preflights scalar constraints and documented sufficient workspace formulas, widens checked arithmetic before narrowing, and validates finite positive query results before any cast. Float query conversion preserves conservative ceil plus 1/64 plus one headroom but rejects excessive counts instead of clamping. Invalid query and local workspace overflow use distinct sentinels mapped before generic negative info. Unavailable backend and allocation failure retain the existing shared sentinel. Root approved internal visibility of the actual Swift error mapper solely for tiny mapping tests; this is not a new public API.

## Oracle and boundary coverage

The numerical references are independent analytic spectra and Double reconstruction, orthogonality and eigen-residual loops. They do not call the provider under test or treat LAPACK as the sole oracle. Power-of-two scales cover subnormal, normal and near-extreme finite values, with signed scales where applicable. Cases include [s,s], [3s,4s], golden-ratio full rank, exact zeros and diagonals, unequal column scales, and the exact dyadic H4·diag(8,4,2,1)·H4ᵀ/4 construction embedded as a 6×4 matrix and transposed as 4×6. The latter has nonorthogonal columns and exercises multiple rotations. The same block supplies a known four-dimensional eigen spectrum and independent AV−VΛ residual.

Every new numerical predicate rejects nonfinite values and shape mismatches. The final scalar allowance is one subnormal Float ULP plus a relative 2e-6 working-error allowance; an explicit control rejects zero for an exact five-subnormal-ULP scalar. Orthogonality and reconstruction use separate allowances for multiple rounded Float factors and accumulation. These tolerances are bounded fixture checks, not a universal forward-error guarantee. Final Float rounding and exact-zero working-column rank deficiency are tested separately.

Pure C tests cover signed32 polynomial cutoffs, SIZE_MAX byte arithmetic, zero and negative counts, Float 2^24 neighbors, fractional and excessive queries, NaN/Inf, and integer-query minimums. The mock compiles the actual C shim and helper with controlled vendor outputs and tracked real malloc/free calls. It establishes local preflight and cleanup without large allocations or vendor calls. It does not establish Accelerate's internal arithmetic. The historical v1/v3 C print label incorrectly called the final eigenvector cutoff “svdCutoff”; the independently asserted polynomials were correct. v4 corrects only that diagnostic label and retains the original logs unchanged.
