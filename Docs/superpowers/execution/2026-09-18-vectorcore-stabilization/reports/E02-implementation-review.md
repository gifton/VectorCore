### Blocking finding E02-IR-1: timeout must leave before process-status access

`ExecutionSchedulingContractTests.boundedRegressionChild`, lines 69–91 in frozen v1, applies a 15-second execution wait and two bounded one-second cleanup waits, but `#expect(!timeout)` records an issue and continues. Accessing process completion properties in that state defeats the intended bounded-child contract. This is the same post-timeout status-access class addressed by EX06.

After retaining/printing the capture, throw a timeout error (or otherwise terminate this test invocation) before either completion-property read whenever the original execution deadline expired. Do not rely on `#expect` to alter control flow. Preserve the original timeout as a failure even if cleanup subsequently succeeds. Keep the current pre-run termination handler and bounded cleanup. Root was notified promptly; a disclosed test-only revision and associated verification are required. No production correction is requested.
