# Historical index-kernel specifications

The Markdown files in this directory are retained design specifications, not
a VectorIndex target or implementation bundled with VectorCore. Their
proposed signatures, buffer layouts, and performance expectations have not
been revalidated as current APIs in this documentation pass.

For Core's supported interfaces, start with the
[documentation index](../../Docs/README.md) and
[package boundaries](../../Docs/Package_Boundaries.md).
For index implementation and usage, consult the separate
[VectorIndex repository](https://github.com/gifton/VectorIndex).

Original filenames remain in place to preserve historical links. Do not infer
that a kernel is available or verified because a specification exists here.
