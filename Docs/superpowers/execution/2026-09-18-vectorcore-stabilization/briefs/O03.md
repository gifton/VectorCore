## Contract and architecture

Preserve public value semantics, element order, dimensions, the 64-byte HybridStorage inline threshold, and DimensionStorage's existing default selection (dimension <=16 uses hybrid regardless of scalar width). Preserve explicit .hybrid/.heap choices and isUsingHybridStorage. Preserve zero initialization and repeating/factory values. There is no binary-layout promise for these unfrozen implementation types, but a larger representation is unnecessary for this repair.

Use the already accepted O01/O02 move-out/restore approach for private enum owners. Before checking or mutating an extracted heap owner, replace the stored enum payload with a nonallocating empty inline placeholder so only actual external aliases remain. Restore the payload with defer on every throwing path. In HybridStorage remove the redundant outer COW allocation; ManagedStorage remains the single heap COW boundary. Scalar writes perform one ownership check; fill performs one mutable buffer borrow followed by one pass, not repeated scalar setter calls. This is an exclusive mutating access: the temporary placeholder must never escape or become observable through a callback. Ordinary and throwing mutable borrows retain partial writes while retained copies remain snapshots; return values and error identity propagate unchanged.

Apply the same ownership discipline to DimensionStorage's hybrid mutation wrappers where the outer enum otherwise retains the extracted HybridStorage. The default managed path is a negative control, not evidence of a historical copying defect; preserve its measured optimized behavior. Make the public mutating isUniquelyReferenced diagnostic reflect the underlying owner after removing only the temporary enum retain. Inline values report true; a retained heap copy reports false; after one detach the changed value reports true. makeUnique must leave an already unique owner alone and detach an actually shared heap owner once. A mutating getter may temporarily move out and restore the same payload, but must not allocate or change data. Do not add persistent reference-count instrumentation or global hooks.

Hybrid copyFrom copies into already initialized floating-point elements using assignment/update semantics, with retained-copy isolation. DynamicVector.resized's copied prefix likewise uses update rather than initialize over its already initialized result. Preserve prefix and fill-tail behavior for grow, shrink, equal and zero dimensions; source remains unchanged. S01's shape and ownership invariants remain in force. Do not activate move-only experimental storage or change lifetime/shape gates; escaped internal slices are O05's separate task.

Remove DynamicVector min/max/clamped's unused zero-result allocation in VectorCoreOperations. Preserve the existing Operations.simdProvider TaskLocal witness: exactly one existing elementWiseMin/elementWiseMax/clip call per successful public operation, original argument order and shape check before provider invocation. Do not bypass custom providers, substitute a static kernel, add a new provider API, change nonfinite policy, or assert that all input/provider-result arrays are redundant. The existing array protocol requires those conversions. A provider spy must still supply distinctive results through the public wrappers. Generic fixed-vector wrappers are controls; do not rewrite them absent a measured, in-scope opportunity.

OWN-22 is a source-established opportunity, not an established optimized regression. Retain before/after Release allocation records for the public wrappers. If the optimizer already removes the unused initial result, report that observation explicitly; do not fabricate a measured reduction, change compiler flags to force one, or close the record as a measured speedup. Return that evidence to root for a qualified disposition of the remaining array-interface opportunity. No broader scoped-provider redesign is authorized by this brief.
