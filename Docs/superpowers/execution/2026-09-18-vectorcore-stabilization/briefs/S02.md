# S02 — Validate dimensions before mutation and aggregation

Root-approved contract; dispatch after S01 acceptance. Breaking changes authorized. Covers OWN-06/API-13/API-19 and bounded lookup extension EX-02.

## Contracts

All three VectorProtocol binary in-place defaults (`inPlaceAdd`, `inPlaceSubtract`, `inPlaceElementwiseMultiply`) precondition equal scalarCount before entering either buffer closure. Direct and generic `+=`/`-=` reject short and long RHS before writes; two empty dynamic vectors are valid no-ops. Preserve existing VectorFactory operator rejection, testing that separate dispatch route. No scalar arithmetic changes.

Make `Operations.centroid(of:)` and `Operations.statistics(for:)` throwing. Empty centroid throws VectorError(.insufficientData) for fixed and dynamic element types. Nonempty zero-dimensional dynamic rows have a valid zero-dimensional centroid; never force-unwrap empty buffer addresses. Empty statistics retains count0/dimensions0/empty component arrays/zero magnitude summary regardless of element type. Nonempty zero-dimensional rows produce countN/dimensions0/empty component arrays/zero magnitude summary.

Preflight every row's scalarCount against the first before processing any row; mismatch throws VectorError.dimensionMismatch. Short/long rows at any position fail before toArray, scalar reads or provider work. S01 guards built-in shape; custom conformers remain responsible for truthful scalarCount/buffer shape. At existing toArray boundaries also verify actual array count before indexed/unsafe reads. Do not retain an O(ND) copy of all rows just to preflight metadata. Local accumulation before discovering a lying custom conformer is not published; failures return no result.

Centroid and already-throwing `Operations.normalize` propagate generic factory errors with `try`, preserving the exact error instead of forcing, wrapping or returning partial results. Normalize operates independently per row (no equal-dimension requirement); empty input returns empty. Numerical normalization and stable statistics remain N01/N03 work.

Factory: batch requires dimension>0 and throws `.invalidDimension` before remainder/division, including empty values. Positive dimension/empty values returns []; positive nonmultiple retains `.invalidData`. Single-vector creation permits zero with empty values, rejects negative dimension with `.invalidDimension` before count matching. Nonthrowing random/zeros/ones/withPattern permit zero, precondition dimension>=0 before ranges/allocation/pattern closure. Basis requires positive dimension (`.invalidDimension` first), then valid index. No new allocation budget.

EX-02: optimalDimension accepts every Int approximation: clamp below/above supported interval to endpoints before subtraction; nearest interior width, smaller width on ties. Source-established until separate RED probe confirms Int.min overflow. No enormous iteration/allocation needed.
