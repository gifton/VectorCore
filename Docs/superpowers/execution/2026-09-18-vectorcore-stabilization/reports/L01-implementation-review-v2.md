Scaled norms and direct division by `alpha-beta` avoid the old Float norm/reciprocal failures; the choice of beta prevents cancellation in that denominator. Backward application produces the thin Q and initialized lower R remains exactly zero. Final conversion checks both Double finiteness and Float representability.

The symmetric Jacobi update and eigenvector rotations use consistent signs. The scaled smaller-root formula avoids theta overflow; its equal-diagonal positive root is valid for either sign of the off-diagonal entry. Only the lower input triangle enters the Double matrix. The dimension-aware threshold uses the full symmetric Frobenius norm, a finite-aware final off-diagonal check, and the bounded sweep policy. Sorting permutes eigenvectors with their eigenvalues.

One-sided SVD uses normalized correlation, Double column rotations and Double normalization before any Float conversion. Its rotation has the same consistent sign convention as the eigen path. Sorting is performed on working Double singular values. The wide transpose/swap maps U and Vt to the correct column-major dimensions without an intermediate Float round trip. Exact-zero working columns and nonzero singular values rounding to Float zero are correctly distinct: the latter still receive normalized factors. A sweep which performs rotations is not itself declared converged; exhaustion may conservatively throw even if a further check would pass, which is within the approved bounded-convergence contract.

Shared shape checks precede finite checks and backend availability. Thin outputs do not exceed the input element count. Successful LAPACK factors/spectra receive finite output checks; eigenvalues-only does not reject the intentionally ignored upper input triangle. Output overflow remains a typed operation failure and underflow rounding is allowed. No convergence, arbitrary conditioning, allocation success or backend-equivalent accuracy guarantee is inferred.

## C boundary and ownership review
